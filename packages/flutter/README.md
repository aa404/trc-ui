# trc_ui

Flutter widgets with a deep black design: near-black backgrounds, graphite cards, thin Montserrat headings, one accent color and pill buttons whose dot stretches on hover.

The Flutter port of [trc ui](https://ui.theringconcept.com). Work in progress.

## Fonts

Montserrat is bundled with the package under the [SIL Open Font License 1.1](fonts/OFL.txt).
